# Excel Interview Questions
### Data Analyst Role — Prep Sheet

## Fundamentals
- What's the difference between VLOOKUP, HLOOKUP, and INDEX-MATCH? Why might INDEX-MATCH be preferred?
- Explain relative vs. absolute cell references (and when you'd use $A$1 vs A1).
- What's the difference between COUNT, COUNTA, COUNTIF, and COUNTIFS?
- How do SUMIF and SUMIFS differ, and when would you need multiple criteria?
- What is the difference between a formula and a function in Excel?

## Data Cleaning & Manipulation
- How would you remove duplicate rows from a dataset?
- How do you handle blank/missing cells before analysis?
- What's the use of Text-to-Columns or Flash Fill?
- How would you split a full name column into first and last name?
- How do TRIM, CLEAN, and SUBSTITUTE help clean messy data?
- What's the difference between Find & Replace and using formulas for text cleanup?

## Pivot Tables & Summarization
- Walk me through how you'd build a pivot table to summarize sales by region and month.
- How do you add a calculated field in a pivot table?
- What's the difference between a pivot table and a regular table with formulas?
- How would you show percentage of total in a pivot table?

## Lookup & Logical Functions
- Explain nested IF statements — and why they can get messy at scale.
- How does IFERROR help in cleaning up formula outputs?
- What's XLOOKUP and how is it an improvement over VLOOKUP?
- How would you do a two-way lookup (matching both row and column criteria)?

## Data Analysis / Statistical
- How would you calculate a running total in Excel?
- What's the difference between AVERAGE and AVERAGEIF?
- How do you build a frequency distribution using COUNTIFS or FREQUENCY?
- How would you identify outliers in a dataset using Excel?

## Charts & Visualization
- How do you decide which chart type fits a given dataset?
- How would you build a dashboard using slicers and pivot charts?
- What's a common mistake people make when visualizing data in Excel?

## Scenario-Based
- Here's a messy sales dataset — how would you clean it and find the top 5 performing products?
- You have two spreadsheets that need to be merged on a common ID — how do you do it?
- How would you flag duplicate customer entries with slightly different spellings?
- If a formula is returning #REF! or #N/A, how do you debug it?

## Advanced (Senior Roles)
- Basics of Power Query for ETL-style tasks in Excel.
- What are array formulas, and when would you use one?
- Difference between Excel functions and VBA macros — when would you reach for VBA?
- How would you use Data Validation to build a dropdown-driven input sheet?
